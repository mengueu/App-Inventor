# Desenvolvimento Mobile — App Inventor

Repositório para registrar as aulas, exercícios e projetos desenvolvidos durante a disciplina de **Desenvolvimento Mobile**, parte do curso técnico em **Desenvolvimento de Sistemas** do SENAI.

## Sobre a disciplina

Nesta parte da disciplina estou aprendendo desenvolvimento mobile utilizando o **App Inventor**, com foco em **sistemas embarcados**. O objetivo é ir além da criação de telas e navegação, explorando a integração de aplicativos com sensores e tecnologias de comunicação, como conexão Bluetooth e Wi-Fi, GPS, acelerômetro, giroscópio, entre outros.

## 🧩 Tecnologias utilizadas

- **App Inventor** — plataforma de desenvolvimento visual baseada em blocos, criada pelo MIT, usada para criar aplicativos Android sem necessidade de escrever código tradicional.
- **Programação em blocos** — lógica construída através do encaixe de blocos visuais, que representam comandos, estruturas de controle e eventos.
- **Sensores e componentes embarcados** — uso de recursos do próprio dispositivo, como Bluetooth, Wi-Fi, GPS, acelerômetro e giroscópio, para criar aplicações que interagem com o mundo físico.
- **MIT AI2 Companion** — aplicativo usado para testar os projetos em tempo real diretamente no celular, sem necessidade de compilar um APK a cada alteração.
- **Android** — sistema operacional alvo dos aplicativos desenvolvidos.

## Por que App Inventor?

O App Inventor foi escolhido para esta etapa da disciplina pois permite:

- Focar na lógica e na integração com sensores, sem a barreira inicial de uma linguagem de programação textual.
- Testar rapidamente o uso de recursos de hardware do celular, como Bluetooth, GPS e sensores de movimento.
- Visualizar o resultado do app em tempo real no próprio dispositivo, através do MIT AI2 Companion.
- Entender conceitos de sistemas embarcados e comunicação entre dispositivos de forma prática e visual, antes de aprofundar em frameworks mais complexos como o React Native.

## ▶️ Como executar os projetos

Pré-requisitos: conta no [MIT App Inventor](https://appinventor.mit.edu/) e o app **MIT AI2 Companion** instalado no celular (ou um emulador configurado).

1. Acesse o [App Inventor](https://appinventor.mit.edu/) e faça login com uma conta Google.
2. Importe o projeto desejado: **Projects > Import project (.aia) from my computer**, selecionando o arquivo `.aia` correspondente na pasta do projeto.
3. Com o projeto aberto, abra o app **MIT AI2 Companion** no celular e escaneie o QR Code exibido na tela do App Inventor para testar em tempo real.
4. Para gerar o aplicativo instalável, use **Build > App (provide QR code for .apk)** ou **Build > App (save .apk to my computer)**.

# Mobile Development — App Inventor

Repository to keep track of the classes, exercises, and projects developed during the **Mobile Development** course, part of the **Systems Development** technical program at SENAI.

## About the course

In this part of the course I'm learning mobile development using **App Inventor**, with a focus on **embedded systems**. The goal is to go beyond building screens and navigation, exploring app integration with sensors and communication technologies such as Bluetooth and Wi-Fi connections, GPS, accelerometer, gyroscope, and more.

## 🧩 Technologies used

- **App Inventor** — a visual, block-based development platform created by MIT, used to build Android apps without writing traditional code.
- **Block-based programming** — logic built by snapping together visual blocks that represent commands, control structures, and events.
- **Sensors and embedded components** — use of the device's own resources, such as Bluetooth, Wi-Fi, GPS, accelerometer, and gyroscope, to build applications that interact with the physical world.
- **MIT AI2 Companion** — app used to test projects in real time directly on the phone, without needing to compile an APK for every change.
- **Android** — target operating system for the applications developed.

## Why App Inventor?

App Inventor was chosen for this stage of the course because it allows:

- Focusing on logic and sensor integration without the initial barrier of a text-based programming language.
- Quickly testing the use of the phone's hardware features, such as Bluetooth, GPS, and motion sensors.
- Seeing the app's result in real time on the device itself, through MIT AI2 Companion.
- Understanding embedded systems and device communication concepts in a practical, visual way, before moving on to more complex frameworks like React Native.

## ▶️ How to run the projects

Requirements: a [MIT App Inventor](https://appinventor.mit.edu/) account and the **MIT AI2 Companion** app installed on your phone (or a configured emulator).

1. Go to [App Inventor](https://appinventor.mit.edu/) and log in with a Google account.
2. Import the desired project: **Projects > Import project (.aia) from my computer**, selecting the corresponding `.aia` file from the project folder.
3. With the project open, launch the **MIT AI2 Companion** app on your phone and scan the QR Code shown on the App Inventor screen to test in real time.
4. To generate the installable app, use **Build > App (provide QR code for .apk)** or **Build > App (save .apk to my computer)**.
